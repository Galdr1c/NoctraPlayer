6
Alt Başlık + Meta

Her zaman görünür. Başlık (kalın, 12px) + meta satırı (sezon/yıl/süre, 10px muted). Hover'da action bar için yukarı kayar.

7
Hover Action Bar

Sadece hover'da görünür. Oynat, Listeme Ekle, Favori butonları. Opacity 0→1 + TranslateY 8→0 animasyonu.

8
Scale-Up Hover

Kartın tamamı hover'da 1.0→1.08 scale + hafif yukarı kayma. Avalonia'da Transitions + ScaleTransform.

Mevcut vs Hedef

Mevcut Kart — Şu anki hali

✗Icon stili — küçük centered ikon, boş gri alan
✗Padding'li kutu — resim etrafında boşluk var
✗Alt bilgi yok — sadece başlık + sezon sayısı
✗Hover efekti yok — scale/animasyon yok
✗Action butonları yok — sadece tıklama var
✗Sabit boyut — 180px WrapPanel

Hedef Kart — Netflix stili

✓Full-bleed poster — resim kartı tamamen kaplar
✓Alt gradient — karanlık örtü + başlık her zaman görünür
✓Meta bilgi — yıl, sezon, puan, tür
✓Scale hover — 1.08x büyüme + yukarı kayma
✓Action bar — hover'da Oynat, Ekle, Favori butonları
✓Progress bar — izleme ilerlemesi
Avalonia Uygulama Notları
Teknik Detaylar

⚡ Avalonia'ya Özel Dikkat Edilmesi Gerekenler

🎨
Gradient Overlay

Avalonia'da LinearGradientBrush ile Bottom→Transparent gradient yapılır. StartPoint="0,1" EndPoint="0,0" ile alta yaslanır. Opacity için GradientStop Color="#F0000000" kullanılır (F0 = 240/255 alpha).

🔄
Hover Scale Animasyonu

Avalonia'da CSS :hover yok. Bunun yerine PointerEntered/PointerExited event veya :pointerover selector ile Styles kullanılır. ScaleTransform + Transitions kombinasyonu çalışır.

📐
Kart Boyutları

Dizi: Width=160, Height=240 (2:3). Film: Width=220, Height=124 (16:9). Grid için UniformGrid veya WrapPanel. Virtualization için VirtualizingStackPanel.

👁️
Hover Action Visibility

Avalonia'da element visibility'yi pointer state'e bağlamak için Style Selector: Button:pointerover Border#ActionBar gibi. Opacity transition ile yumuşak geçiş yapılır.

🖼️
Resim Yükleme

Zaten kullandığın RemoteImage kontrolü çalışır. Stretch="UniformToFill" ile full-bleed yapılır. Poster yoksa gradient fallback göster.

⚡
Z-Index Sorunu

Hover'da kart büyüdüğünde komşu kartların üzerine gelir. WrapPanel'de Z-Index çalışmaz. Çözüm: hover state'de kartı Canvas'a taşı VEYA ZIndex attached property kullan.
